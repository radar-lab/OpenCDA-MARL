## Usage Examples

=== "Basic Map Loading"

    ```python
    from omegaconf import DictConfig
    import carla
    from opencda_marl.core.world.map_manager import MARLMapManager

    # Setup with detailed configuration
    config = DictConfig({
        "map": {
            "name": "Town05",
            "safe_distance": 5.0,
            "spawn_offset": 2.0,
            "dest_offset": 2.0
        }
    })
    client = carla.Client("localhost", 2000)

    # Load map and get spawn/destination pairs
    manager = MARLMapManager(config, client)
    spawn_dest_pairs = manager.get_spawn_points(num=4, dest=True)

    # Visualize junction analysis
    manager.draw_junction_centers(life_time=30.0)
    manager.draw_spawn_points(life_time=30.0)
    ```

=== "Custom Map Registration"

    ```python
    # Register custom map with validation
    manager.register_custom_map(
    ```

=== "Integration with OpenCDA"

    ```python
    from opencda.scenario_testing.utils.sim_api import ScenarioManager
    from opencda_marl.core.world.map_manager import MARLMapManager

    # Initialize with MARL spawn system
    map_manager = MARLMapManager(config, client)
    spawn_dest_pairs = map_manager.get_spawn_points(num=4, dest=True)

    # Create OpenCDA vehicles with MARL spawn points
    scenario_manager = ScenarioManager(scenario_params)
    vehicles = []

    for i, (spawn_tf, dest_tf) in enumerate(spawn_dest_pairs):
        vehicle = scenario_manager.create_single_cav(
            spawn_transform=spawn_tf,
            config_override={
                "agent_id": f"agent_{i}",
                "destination": dest_tf
            }
        )
        vehicles.append(vehicle)
    ```
