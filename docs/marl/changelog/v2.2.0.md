# v2.2.0 — a public wheel without the UCLA-licensed material

**Theme**: the library can be published to a package index without moving any
UCLA-licensed software, and a SUMO run needs nothing from the OpenCDA core.

## Added

- **A public wheel.** `pixi run wheel --public` builds `dist/public/opencda_marl-*.whl` from
  a temporary tree that leaves out every path `THIRD_PARTY_NOTICES.md` lists under UCLA's
  Academic Software License: the vendored `opencda/` core, the copied OpenCDA scenario
  configs and the three files with adapted OpenCDA code. Its licence metadata is
  `Apache-2.0 AND MIT`, and it has no source distribution. The list of omitted paths is
  read from the notice itself, so the two cannot drift apart.
- **The SUMO benchmark, the library, the plugins and the bundled baselines run on it.**
  A test runs a SUMO episode from the unpacked public wheel in a process where importing
  `opencda` raises.
- **A pointed error for CARLA.** Starting the CARLA backend without the core now says to
  run from a repository checkout, or to install the full build from Git.

## Changed

- The SUMO path no longer imports the OpenCDA core: `CavWorld` is a type-only import in
  `pipeline_builder.py`.
- `pixi run wheel` still builds the full wheel (with the core) for installing from Git
  (`pip install git+https://github.com/radar-lab/OpenCDA-MARL.git@v2.2.0`). It is never
  uploaded to a package index.

## Known issues

The known issues listed for [v2.1.0](v2.1.0.md) still apply; a fix release addresses them.
